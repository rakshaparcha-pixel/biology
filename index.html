Comparison: Asexual vs Sexual Phase

Feature Asexual Phase (In Man) Sexual Phase (In Mosquito)
Host Type Primary / Intermediate Host (Man) Secondary Host & Vector (Female Anopheles)
Location Intracellular (Liver hepatocytes & Red Blood Cells) Extracellular (Gut lumen, gut wall, haemocoel, salivary glands)
Processes Pre- & Exo-erythrocytic schizogony, Erythrocytic schizogony, Gametocytosis Gametogenesis (Exflagellation), Fertilisation, Encystment, Sporogony
Ploidy Haploid (n) Gametocytes (n), Zygote/Ookinete (2n), Sporozoites (n)
Pathological Effects Causes malaria symptoms (chills/fever from haemozoin release) No pathogenic symptoms in mosquito vector
